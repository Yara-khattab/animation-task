# Animation Task 

This project is a front-end animation task developed as part of the training program at **SEF Academy**.  
The task focuses on practicing and improving animation skills using pure front-end technologies.

## 🛠️ Technologies Used
- HTML
- CSS
- CSS Animations
- CSS Transitions

## 🎯 Features
- Smooth and visually appealing animations
- Responsive behavior across different screen sizes
- Clean and organized code structure
- Enhanced user experience through motion and interaction

## 📌 Task Description
This task was assigned by **SEF Academy** to help trainees gain hands-on experience with front-end animations.  
It aims to demonstrate how animations can be used effectively to improve UI/UX and make web interfaces more interactive and engaging.

## 🚀 Learning Outcomes
- Understanding the fundamentals of CSS animations and transitions
- Applying animations in real front-end scenarios
- Improving attention to design details and motion timing
- Building more dynamic and attractive user interfaces
